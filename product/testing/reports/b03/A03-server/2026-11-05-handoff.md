- Default composition constructs exactly one `ChatService(settings.chat_history_dir)`
  without invented tools. Frozen GET/POST `/api/conversations`, GET
  `/api/conversations/{conversation_id}` and POST
  `/api/conversations/{conversation_id}/messages` delegate to that service.
  List/create/read and the async-send bridge execute in the route worker pool,
  keeping early M15's synchronous storage reads off the ASGI event loop.

  assistant response on success. No API exposes context or the private ledger.
  Strict frozen bodies reject client messages/ledger/tool results. Invalid-input
  errors do not echo sensitive input. `ChatServiceError.response/status_code`
  are translated directly, including retryable conflicts and storage failures.
- Actual early M15 known-thread sends return `unsupported` / 501 without user
  or assistant appends, with or without a configured key. Unknown threads stay
  `not_found` / 404. Explicit `chat_service=None` means service unavailable / 501;
  no alternate global history, model or fabricated reply is supplied.

  literals and `Settings.debug_enabled`. The frozen schema requires
  `chat_available == (chat_state == 'configured')`, so this boolean describes key

  No substitute drawing or source evidence is generated.
