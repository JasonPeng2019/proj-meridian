## Primary-source diagnosis

The actual `development/uv.lock` pins FastAPI 0.162.0, Starlette 1.10.0,
HTTPX 0.28.1 and Uvicorn 0.54.0. Read the exact tagged primary sources:

- [HTTPX URL.path](https://raw.githubusercontent.com/encode/httpx/0.28.1/httpx/_urls.py),
  lines 225–235: returns `unquote(path)` once.
- [Starlette TestClient](https://raw.githubusercontent.com/Kludex/starlette/1.10.0/starlette/testclient.py),
  lines 215–219 and 257–262: takes `request.url.path`, then calls `unquote(path)`
  when constructing the HTTP ASGI scope. Its legacy HTTPX branch therefore
  decodes that path twice in combination with HTTPX 0.28.1.
- [Uvicorn h11 request scope](https://raw.githubusercontent.com/encode/uvicorn/0.54.0/uvicorn/protocols/http/h11_impl.py),
  lines 183–198: partitions the raw target, decodes/unquotes once and supplies
  that result as `scope['path']`, retaining the original `raw_path`.
- [HTTPX ASGITransport](https://raw.githubusercontent.com/encode/httpx/0.28.1/httpx/_transports/asgi.py),
  lines 97–107: directly forwards `request.url.path` and retains the encoded
  `request.url.raw_path` without applying another unquote.

`main.py` has no application unquote. Its detail handler uses the final ASGI ID
to select a declared fixture exactly. **Inference from these pinned sources and
the remote failure:** the failed assertion exercised TestClient's extra decoding,
not a demonstrated production route defect. Changing application decoding would
alter the intended contract to accommodate the test transport.

## Repair and limits

The existing fixture-route case now uses HTTPX `AsyncClient` / `ASGITransport`
only for the paired encoding checks. An observing ASGI wrapper records the actual
`path` and `raw_path` before forwarding to the unchanged real app. For every
declared fixture ID, including drawing and slash-bearing BOM IDs, it asserts:

- Singly encoded target: scope path is the decoded ID, raw path is the singly
  encoded target, and the route returns 200 with that exact part ID.
- Doubly encoded target: scope path retains the singly encoded text, raw path
  retains the doubly encoded target, and the route returns frozen `not_found` / 404.

TestClient remains for the other fixture/history/error/SPA checks. The repair
